## 🌟 Why This Exists (Solving Highway Range Anxiety)

While India has over 14,500+ operational CNG stations within municipal city limits (operated by PNGRB-licensed City Gas Distribution entities such as IGL, MGL, MNGL, Adani Total Gas, Torrent Gas, and GAIL Gas), long-distance highway road trips present critical challenges:

1. **Access-Controlled Mainline Restrictions:** Fuel plazas are strictly limited to designated Wayside Amenities (WSA) or require exiting via cloverleaf toll interchanges.
2. **Carriageway Directionality:** Many expressways do not have bidirectional median crossovers. Missing a station on your side can result in a 60–100 km penalty.
3. **Dispenser Pressure Variance:** Standard factory-fitted CNG vehicles require **200 BAR continuous pipeline pressure** to achieve their full 200–250 km highway driving range.

This repository provides open metadata for developers, researchers, and road trippers. For full interactive kilometer-by-kilometer chainage maps, directional carriageway filters, and live station coordinates, visit **[CNGbunk.com Highway Routes](https://cngbunk.com/routes/)**.

## ⚡ Quick Start & Programmatic Usage

### npm Package (Node.js & TypeScript)

Install the package directly into any modern JavaScript or TypeScript project:

```bash
npm install india-highway-cng-routes
```

```javascript
import { findCorridor, getCorridorUrl, getLivePriceUrl } from 'india-highway-cng-routes';

// 1. Query expressways by name or route
const results = findCorridor('yamuna');
console.log(results[0].highway); // "Yamuna Expressway"
console.log(getCorridorUrl(results[0].slug)); // "https://cngbunk.com/routes/yamuna-expressway/"

// 2. Fetch live price tracker link
console.log(getLivePriceUrl()); // "https://cngbunk.com/cng-price/"
```

### Python 3 (CLI / Standalone)

```bash
# Clone the repository
git clone https://github.com/abhi09123/india-highway-cng-routes.git
cd india-highway-cng-routes

# Search for any corridor (e.g., Yamuna Expressway, Samruddhi, NH 48)
python3 examples/lookup_highway.py yamuna
```

**Output:**
```text
--- Found 1 Corridor(s) for 'yamuna' ---
🛣️  Yamuna Expressway (Greater Noida -> Agra)
   Length: 175.2 km
   Interactive Milestone Map: https://cngbunk.com/routes/yamuna-expressway/
```

### Local Node.js Script

```bash
node examples/lookup_highway.js samruddhi
```

## 📜 Statutory Regulatory References

* **PESO (Petroleum and Explosives Safety Organisation):** [Gas Cylinders Rules, 2016 (Rule 35)](https://peso.gov.in/) governing mandatory 3-year hydrostatic stretch testing.
* **PNGRB (Petroleum and Natural Gas Regulatory Board):** [CGD Geographical Area Authorizations](https://pngrb.gov.in/) oversight.
* **MoRTH / NHAI:** [National Highways Fee (Determination of Rates and Collection) Rules 2008](https://nhai.gov.in/).
