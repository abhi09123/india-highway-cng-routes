💻 Developer SDK & Open Data API

Incorporate Indian alternative fuel highway corridor metadata directly into your Node.js, TypeScript, Python, or GIS applications.

# Install via npm registry npm install india-highway-cng-routes // Node.js / ES Module Usage const { getCorridors, findRoute } = require('india-highway-cng-routes'); // Query major transit route const route = findRoute('Delhi', 'Jaipur'); console.log(route.highway); // "NH 48" console.log(route.interactive_map_url); // "https://cngbunk.com/routes/delhi-jaipur-nh48/"
