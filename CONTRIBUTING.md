# Contributing to India Highway CNG Corridors

Thank you for your interest in contributing to open mobility data for Indian motorists!

## How You Can Contribute

1. **New Expressways / Corridors:**
   - If a new national expressway or highway bypass has operational CNG dispensing, submit an issue or pull request adding the corridor overview in `data/major_highways_summary.json`.

2. **Live Data Verification:**
   - Forecourt station coordinates, operating hours, and 200 BAR pipeline pressures are verified and indexed directly on [CNGbunk.com](https://cngbunk.com/).
   - To report a newly opened pump or submit feedback on a specific highway milestone, use the verification feedback portal on [CNGbunk Data Verification](https://cngbunk.com/how-we-verify-data/).

## Code of Conduct

Please maintain professional, respectful, and fact-checked communication in all issues and pull requests.
